# Verifika² · CRM - Web local

## Ejecutar servidor

```bash
python3 web/server.py --db data/erp_import2.sqlite --port 8000
```

Luego abre:

```
http://127.0.0.1:8000
```

## Logo

El logo del software se sirve desde `assets/verifika2/` (por defecto `assets/verifika2/verifika2_wordmark_check_green_transparent.png`).
